Release Readout · Aperia Skills Toolkit · 0.8.0

Toolkit 0.8.0
Styles Are Injected, Not Typed

This release moves stylesheet delivery from the model to a script, returns the palette and the type ramp to a single source, and adds checks that fail the drift the old process allowed. Every change is in the brand layer, the component layer or the two document skills; no output format changed.

AudienceToolkit Maintainers
ScopeBrand, Components, Both Skills
DateSeptember 2026

Summary

What 0.8.0 Is For

One release with one theme: remove the places where the same value had to be typed twice, and add a check wherever removing it was not possible.

Direction

The Script Owns The CSS

A document carries a style marker and nothing else. ui-components/assemble.py fills it with the layer files in order, byte for byte, and replaces its own block on re-run.

Consolidation

One Palette, One Ramp

slides.css reads tokens.css instead of restating ten hexes and the type ramp. qa.py and validate.py both read the palette through the new brand/palette.py.

Compliance

Shipped CSS Follows Its Own Rules

Six chart label sizes moved onto the --text-* ramp, a new --radius-sm replaced every small literal radius, and body weight is set once in tokens.css.

Documentation

Stale Text Corrected

Version stamps, skill names, the "three skills" and "720px" claims, and MAINTAINING.md's edit order, which 0.7.0 had inverted, are all fixed.

Verification

How The Release Was Checked

The release was verified in one pass, end to end: a real document written against a bare marker, assembled by the script, then read by the checks that now enforce the rules the CSS follows.

1
Write Against A Bare Marker
examples/toolkit-0-8-0-release.html was written with create-report, carrying only the style marker and its own second style block, with no stylesheet typed by hand.
2
Assemble From The Layers
assemble.py filled the marker with the layer files in order. Re-running replaced the injected block from the same recipe rather than appending a second one.
3
Run The Checks
validate.py ran the widened palette check plus the four new ones over the repo, with check 6 now including skills/. qa.py read the palette through brand/palette.py rather than its old hardcoded set.
4
Read The Output
The assembled example is the shipped proof: this release written up in the format the release changes, so a regression in injection shows as a broken document rather than a silent diff.
Result: the example assembles from a bare marker, re-runs cleanly, and passes validate.py with the four new checks enabled.
Guardrail Found

The assemble script refuses a layer file containing a closing style tag. A browser treats that tag as the end of the block even inside a comment, so an otherwise valid layer file would silently truncate every document it was injected into.

Not Covered

The checks read source text, not rendered output. Nothing in this release verifies that an assembled document prints correctly or that a component collapses at a narrow viewport; those remain manual steps in each skill's checklist.

The Rule This Release Establishes

A value that appears in two files will diverge. 0.8.0 removed the duplicate wherever a script could own it and added a check wherever it could not. Later changes should be read against that test before they land.

Own It

If a script can produce the text, the script produces it. Nothing inside an injected block is typed.

Check It

If a duplicate cannot be removed, a check fails when the copies diverge.

Record It

If a value has to sit off-token, it goes in DEVIATIONS.md with a section number, or nowhere.

Two Things To Confirm

Before the next release: confirm the deviation audit in step 1 is worth doing now rather than at 0.9.0, and decide who owns wiring validate.py into the commit path.
