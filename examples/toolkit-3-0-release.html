Apply Branding

The Gap It Closes

  • Loads the brand layer for any artifact
  • Covers what the other two skills do not
  • Carries no format machinery of its own

When Not To Use It

A long-form document is still create-report, and slides are still create-slides.

The point is that the brand layer only ever loads through a skill. Anything built outside one was branded from memory, which is exactly how off-palette values get in.

The Brand Layer Tightens

This is the section with the longest tail. It changes how every size is written in both themes, so it is worth the four minutes even though nothing here breaks an invocation.
The Type Scale

The Scale In Three Numbers

10
Sanctioned steps, from the Figma design system
12px
On-screen floor, labels and legends included
0
Raw px font sizes left outside the token blocks

The zero is the one that holds: a size nobody can write by hand cannot drift.

Figma also holds a ten and an eleven pixel step. Both sit under the on-screen floor, so they stay print and Figma only and the web ramp starts at twelve.
One Ramp

Three Tiers, One Set Of Names

TokenFactorWhereFloor
--text-*1xReport body, deck chrome12px
--slide-text-*1.625xSlide face body19.5px
--slide-display-*3.25xSlide headlines58.5px
Why 1.625: a slide is a fixed canvas scaled to the viewport, so 12px has to be written as 19.5px to survive the shrink.
The suffix always names the brand step it mirrors, so a reader can trace any slide size back to the ramp. Nineteen point five holds the twelve pixel minimum down to an eleven eighty viewport.
Housekeeping

One Typeface, One Token File

Two long-standing splits in the brand layer are closed.

  • Inter only, no second typefaceLabels take their distinction from case, tracking and colour.
  • tokens.css is the single token filevalidate.py reads the palette from it directly.
JetBrains Mono was never in the guideline. It arrived with the report theme and stayed because nothing checked it, which is the same failure mode as the palette allowlist.
